# Optical Intelligence

**Optical Intelligence** explores whether ambitious technology ideas can work in the real world.

I use physics-based models, engineering analysis, and Python simulations to evaluate the feasibility and performance of emerging technologies. The site also provides Python code, simulations, and technical tools to help explore and understand these technologies.

The goal is simple: **Start with the physics. Build the model. Run the numbers.**
